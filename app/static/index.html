ALERTS, STRAIGHT TO YOUR PHONE

Connect Telegram

  1. Create a bot with @BotFather using /newbot.
  2. Open your bot in Telegram and send /start.
  3. Find your chat ID using Telegram’s getUpdates API. Follow the instructions in docs/RUNNING.md.
  4. Copy .env.example to .env and set: 
    TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
  5. Restart Job Watcher, then select Send test message on the Telegram delivery page.

Keep your token private. It stays on the server and never appears in this dashboard or the repository.
